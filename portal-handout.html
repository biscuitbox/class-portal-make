단계별 체크 — 끝낸 단계에 표시

  • 1단계 AI로 만들기 — 프롬프트 1을 붙여넣었고, 미리보기에서 알림을 추가해 봤다
  • 2단계 파일로 저장 — 폴더의 index.html을 더블클릭하면 크롬에서 안내판이 열린다
  • 3단계 고치고 더하기 — 기능을 하나씩 넣고, 넣을 때마다 다시 저장했다
  • 4단계 인터넷에 올리기 — 교실 TV에서 내 주소로 안내판이 열린다
  • 5단계 여러 기기 공유 — 로그인해서 고친 내용이 다른 기기의 학생용 주소에도 보인다

파일 저장 규칙 (2단계)

받기제미나이 내보내기 › 코드 다운로드 · 안 되면 코드 복사 → 메모장에 붙여넣기
메모장 저장파일 › 다른 이름으로 저장 → 파일 형식 모든 파일(*.*) · 인코딩 UTF-8
이름올리는 파일은 항상 index.html · 보관용 복사본은 index_1.html, index_2.html
확인코드가 <!DOCTYPE html>로 시작해 </html>로 끝나는가 · "기존 코드 그대로" 같은 생략이 없는가

깃허브에 올리는 순서 (4단계)

1저장소 만들기 — 오른쪽 위 ＋ › New repository → 이름 class-portal → Public → Add README 켜기 → Create repository
2파일 올리기 — Add file › Upload files → index.html만 끌어다 놓기 → Commit changes
3페이지 켜기(처음 한 번) — Settings › Pages → Branch main · /(root) → Save
4확인 — 1~2분 뒤 Pages 화면 새로고침 → Your site is live at 주소 열기 · 고친 뒤엔 같은 이름으로 다시 올리고 Ctrl+F5

내 파이어베이스 — 5단계에서 적어 두기

프로젝트 이름
로그인할 선생님 이메일
승인된 도메인에 넣은 값.github.io  (https:// 와 /저장소이름/ 은 빼고)

파이어베이스 순서 — console.firebase.google.com

  • ① 프로젝트 만들기 — 새 Firebase 프로젝트 만들기 → 영문 이름 → 애널리틱스 끄기 → 만들기 (결제 정보 등록 안 함)
  • ② 구글 로그인 켜기 — 보안 › Authentication › 로그인 방법 › Google → 사용 설정 → 지원 이메일 → 저장
  • ③ 데이터베이스 — 데이터베이스 및 스토리지 › Firestore → 데이터베이스 만들기 → Standard → asia-northeast3 (Seoul) → 프로덕션 모드
  • ④ 보안 규칙 게시 — Firestore 규칙 탭 → 전부 지우고 가이드의 규칙 붙여넣기(내 이메일 확인) → 게시
  • ⑤ 설정값 복사 — ⚙ 설정 › 일반 › 내 앱 › </> → 닉네임 → 앱 등록 → const firebaseConfig = {…}; 복사
  • ⑥ 승인된 도메인 — 보안 › Authentication › 설정 › 승인된 도메인 › 도메인 추가 → 아이디.github.io
  • ⑦ AI에게 연결 부탁 — 가이드의 파이어베이스 프롬프트에 firebaseConfig·이메일을 넣어 보내기 → 저장 → 다시 올리기
  • ⑧ 내 주소에서 확인 — 구글 로그인 → 알림 추가 → 다른 기기 학생용 주소에서 보이는지 (미리보기·내 컴퓨터 파일에서는 로그인 안 됨)
